# 代码审查与测试报告

**项目**：面向高校食堂的农产品直供溯源与结算管理系统（`canteen_trace`）
**日期**：2026-11-09
**范围**：后端 Spring Boot 3.2.5 / 前端 Vue 3 / MySQL schema / 配置与运维脚本
**结论摘要**：功能主流程可用、金额公式在真实数据上零偏差；但**认证授权层存在系统性缺口**——服务端无角色鉴权、JWT 密钥硬编码、文件接口整段免鉴权，三项均已实测复现，属于上线阻断级问题。本次补齐了项目此前完全缺失的代码级自动化测试。

1. 项目**无任何代码级测试**：`backend/src/test` 不存在，`pom.xml` 虽引入 `spring-boot-starter-test` 却从未使用；现有 `tools/test_api.ps1`、`test_flow.ps1`、`pw_check.cjs` 都是外部黑盒脚本。
2. 现有测试断言偏弱：`test_api.ps1:19` 仅判 `code == 200`；`pw_interact.cjs:58,87` 含恒真断言 `ok(rowsAfter >= 0)` / `ok(true)`；`pw_check.cjs:62-67` 计算的 `rows` **不进入** `ok` 判定。因此 README「38 项 / 29 项 / 27 路由全部通过」高估了真实覆盖。
3. 演示数据已被既有端到端脚本写脏：实际 330 条订单，README 与 `docs/测试报告.md` 记录为 326 条；`tools/test_flow.ps1` 无 teardown，每跑一次新增订单/结算并扣减农户信用。

**环境坑（复跑必读）**：
- 直接 `java -jar` 会被环境注入 `server.port=62531` 且该端口被占用而启动失败，必须显式加 `--server.port=8080`。
- 会话存在 `HTTP_PROXY=http://127.0.0.1:62550`，所有本地请求必须绕过代理（curl 加 `--noproxy '*'`，Python 用 `ProxyHandler({})`），否则得到 502/000。
- Playwright 缓存为 chromium-1223/1248，当前全局包需要 1228，故巡检脚本改用系统 Edge。

## 四、修复优先级建议（按投入产出比）

1. **先堵认证授权**（P0-1/2/3/4）：拦截器加 URL-角色映射 + 移除 `/api/files/**` 白名单 + secret 外置 + `type` 路径白名单。这四项改动量不大，但能把「任意登录用户可接管系统」直接归零。
