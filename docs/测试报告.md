## 六、遗留说明

1. 溯源存证为 **数据库内 SHA-256 简易存证**，不具区块链级防篡改能力（与设计文档一致）。
2. 未接入真实支付与短信/微信通知，结算仅做记录与对账，通知为站内信。
3. 定价、销量预测、压力测试不在本期范围。
4. 演示数据由 `tools/gen_data.py` 生成，可通过重建数据库复现。
