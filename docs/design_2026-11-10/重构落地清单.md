## 一、落地策略：外壳与内容分离

28 个 view 的 `<template>` 与 `<script setup>` **一个业务字段都不重敲**（经验库 L-020）。原因：所有 view 的 scoped 样式都通过 `var(--c-*)` 取色，只要把 `--c-*` 重定义为三套设计 token 的别名，换肤就是一次变量重算，业务 DOM 完全不动。

| 层 | 文件 | 改动 |
|---|---|---|
| 设计系统 | `styles/tokens.css` | 全量重写：三套 `html[data-scheme]` token + `--c-*` 兼容别名 + Element Plus 变量映射 |
| 设计系统 | `styles/global.css` | 全量重写：去光晕/去渐变、组件语言、动效规范、交互组件样式、深色 EP 适配 |
| 布局 | `layout/AppLayout.vue` | 全量重写：B 70px 窄栏 / A 218px 编号栏 / C 顶部横栏三态 |
| 交互 | `components/CmdPalette.vue`（新） | `⌘K` 命令面板，直达任意页面与常用操作 |
| 交互 | `utils/ui-enhance.js`（新） | 路由级 DOM 增强：实时搜索、状态 chip、批量条、行内操作、数字滚动、时间线展开 |
| 特例 | `views/login/index.vue` | 只改 `<style>` 与品牌区外壳，保留全部 `v-model` / `submit` / 安全约束 |
| 特例 | `router/index.js` | 增加 `meta.scheme` + `afterEach` 应用主题 |
| 资产 | `public/design/*.png`（新） | A/B/C 三张主视觉复制进前端静态目录 |
| 业务 view | 其余 27 个 | **0 行改动**，由设计系统统一换肤 |

3. **内容保真**：交付前对 28 个 view 做「备份 vs 重构后」纯文本比对，业务字段零丢失。
4. **门禁**：`npm run build`、`mvn test`（66 用例）、`review_system_test.py`（69 项）、`review_pw_check.cjs`（30 路由 + 控制台 4xx）。
5. **主题**：`html[data-scheme]` 单一真源；三套对比度独立复算且互不重复，均 ≥ 4.5:1。
