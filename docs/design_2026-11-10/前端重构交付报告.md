## 三、目检发现并修掉的缺陷（数值断言抓不到）

真实浏览器截图逐张目检后发现 4 类"换外壳时的残留冲突"，已全部修复并复验：

1. **全局类名污染局部组件**：`global.css` 的 `.card-head{display:flex}` 命登录登录页同名类，把「欢迎回来」和副标题挤成一行 → 登录页 scoped 里显式 `display:block`。
2. **注入式交互与原生控件重复**：订单页自带 `.tabs-row .tab-btn` 状态筛选，交互层又生成一套 chip，出现两条筛选工具条 → 注入前先检测原生同类控件，只把即时搜索并进 `.filter-bar`。
3. **行内操作挤占原操作列**：复制按钮追加在最后一列，和「详情 / 追踪」黏在一起 → 改挂首列单号后，加分隔线。
4. **深色下硬编码白底残留**：`Dashboard.vue` scoped 里 `.todo-item:hover{background:#f7fbf9}`、`.date-chip{background:#fff}` 在 C 方案出现刺眼白块 → 全局用设计 token + `!important` 兜底；toast 也改为面板色。

> 这三类（类名冲突、原生控件重复、硬编码色残留）已写入经验库 L-029。

## 五、怎么体验

1. 启动：`start.bat`（后端 8080 + 前端 5173），或分别 `java -jar … --server.port=8080` / `npm run dev`。
2. 登录后按 **`Ctrl+K` / `⌘K`** 打开命令面板，输入「结算」「溯源」等直接跳转。
3. 顶栏「外观」选自动 / A / B / C；默认自动会按页面智能分配，进入驾驶舱自动变深色、进入溯源自动变纸质。
4. 表格页在筛选行最左侧直接输入即可即时过滤；勾选多选列会出现批量浮动条。

## 七、已知边界

- **混搭的视觉跳跃**：从深色驾驶舱切回浅色表格页会有明显明暗切换，这是「按页面分配皮肤」的固有代价；顶栏可一键锁定任一方案消除跳跃。
- **表头排序是 DOM 层排序**：不触碰 Vue 数据与后端分页，只排当前页可见行；跨页全局排序仍需后端支持。
- **ECharts 系列色仍是页面里写死的绿色**：深色下可读（已目检），若要完全随主题变色，需把 Dashboard 的 `option` 色板改为读设计 token。
- **其余遗留与重构无关**：定时任务无分布式锁、审计日志同事务、内存分页 N+1、看板增长率口径、前端尚无 vitest/eslint/CI（沿用修复阶段结论）。
- **构建环境**：本机 esbuild 清理系统临时目录偶发 `Access is denied`，已在命令里把 `TMP/TEMP` 指向 `frontend/.build-tmp` 规避（经验库 L-030）。
