# 接口文档（RESTful）

- 基础路径：`http://127.0.0.1:8080/api`
- 认证：除 `/auth/login`、`/auth/roles`、`/common/health`、`/files/**` 外，均需请求头 `Authorization: Bearer <token>`
- 统一响应：`{ "code": 200, "message": "操作成功", "data": {...} }`；`code` 401 未登录、403 无权限、404 不存在、409 并发冲突、423 账号锁定、500 业务异常
- 分页响应：`data.page = { records, total, page, size, pages }`

## 一、认证 `AuthController`

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/auth/login` | `{username, password, remember}` → `{token, user, roleName, menus, perms}` |
| GET | `/auth/me` | 当前用户 + 菜单 + 权限标识 |
| POST | `/auth/logout` | 退出（在线状态置 0） |
| GET | `/auth/roles` | 登录页角色快捷选择（含演示账号） |

## 二、公共 `CommonController`

## 六、质检配送员 `InspectorController`（前缀 `/inspector`）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/tasks` | 今日质检任务、统计、近 7 日合格率 |
| GET | `/quality/{orderId}` | 质检录入数据（批次号、样品、检测项模板、标准） |
| POST | `/quality` | 提交质检 `{orderId,batchNo,sampleQty,result,items,remark}`；合格→生成批次+二维码+SHA-256，不合格→驳回+扣信用+生成预警 |
| GET | `/deliveries` | 配送任务（当前任务、任务表、车辆、温度预警） |
| GET | `/deliveries/{id}` | 配送单详情 |
| POST | `/deliveries/{id}/start` | 开始配送（40→50） |
| POST | `/deliveries/{id}/arrive` | 扫码交付（50→60） |
| PUT | `/deliveries/{id}/temperature` | 更新车厢温度 |
| GET/POST | `/exceptions` | 异常上报（类型/等级/对象/描述 → 生成食安预警） |
| GET | `/trace` | 批次溯源 |
